# Changelog

## 0.1.0

- Initial community stdio bridge for the official NanoKVM Go MCP service.
- Retain upstream tool discovery and add bounded input batching, complete relative phone gestures, and local portrait screenshot cropping.
- Preserve original upstream scrolling/screenshots by default; enable their iPhone adaptation explicitly with phone mode.
- Add capture freshness, explicit release, conservative animation handling, overlap checks, and per-stage diagnostics.
- Add bounded macOS chat reading with Apple Vision OCR, group-header verification, source-linked text, and positional deduplication.
- Package external configuration and credential-file references, verified TLS with optional dedicated CA/name/fingerprint checks, and separate web-session credentials.
- Include offline protocol/image tests and Ubuntu/macOS wheel checks.
